## Deskripsi

Repository ini berisi latihan dasar penggunaan Array dalam JavaScript, meliputi pembuatan Array, mengakses dan mengubah elemen, serta penggunaan properti `includes()dan indexof(`

## Daftar Latihan

- Soal 2 — Mengolah daftar buku
- Soal 3 — Mencari psesrta
- Soal 4 — mengolah nilai ulangan
- Soal 5 — daftar barang

## Cara Menjalankan Program

1. Buka folder proyek menggunakan Visual Studio Code.
2. Buka Terminal.
3. Jalankan file JavaScript menggunakan Node.js.

Contoh:

```bash
node soal-1.js
```

Ganti nama file sesuai soal yang ingin dijalankan.
